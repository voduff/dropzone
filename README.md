# Dropzone

An offline, single-player battle royale made in Unity 6. You and 9–24 bots ride the Drop Bus over an island, skydive
into one of nine named locations, loot weapons of five rarities, harvest wood and build walls, floors and ramps, and
fight while the storm closes in. Last one standing wins.

**Play in your browser:** https://voduff.github.io/dropzone/

## Controls

| Action | Key |
|---|---|
| Move / look | WASD / mouse |
| Jump · jump from bus · open glider | Space |
| Sprint / crouch | Shift / Ctrl or C |
| Fire / aim | Left / right mouse |
| Reload | R |
| Select slot / pickaxe / cycle | 1–5 / F / mouse wheel |
| Interact (hold) — pick up, open chests | E |
| Drop item | G |
| Build mode (then 1 wall, 2 floor, 3 ramp, R rotate) | Q |
| Map | M |
| Pause | Esc (in the browser, releasing the mouse pauses; click to resume) |

Click the game to capture the mouse. A desktop browser with WebGL 2 is required; the first load downloads the game
(it is cached afterwards).

This repository contains the browser build only.
